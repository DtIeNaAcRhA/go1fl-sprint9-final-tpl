Многопоточность в Go

Написана небольшая программу,
которая находит максимальное значение в слайсе целых положительных чисел. Даная программа покрыта unit-тестами.
Задача тривиальная и решается довольно просто, если решать её в один поток. Но если слайс содержит очень много элементов, например, 10 миллионов, то нахождение максимума может занять какое-то время. 

Созданы три функции:
1) Функция генерации данных generateRandomElements() 
2) Функция нахождения максимума maximum() 
3) Функция нахождения максимумов в частях слайса maxChunks()
